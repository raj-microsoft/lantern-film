# Lantern visual system

An animation screening folio: the film is the first viewport's primary artifact, with a quiet native player and a warm original cut-paper world. The petrol surround (#20383f) puts the visitor in an evening screening environment. The lower folio is sage (#e2e8d9), carrying the daytime world into legible production notes; ink is #233b42. Golden Lantern (#f3bd61) is the subject, not a generic UI accent system.

Self-hosted Figtree carries film and page. Display weight 550, body 400, measured numerals tabular. Large headings stay below 6rem. The desktop folio uses paired introductions and three-column shot strips; mobile uses one text column, two shot columns, and an explicitly scrollable script table. Open rows replace boxed UI cards. No decorative shadows or gradients.

Native media controls do not autoplay. Shot buttons pause and cue the movie, then focus its player; reduced-motion disables smooth scrolling and CSS transitions. Visible keyboard outlines and a skip link are included. A separate transcript, burned-in captions and optional text track provide the script without sound.

All shipping raster images come from src/build_film.py: poster.jpg at frame 60 and six shot stills at frames 60/180/330/510/675/840. No external imagery. Font license and media provenance are recorded in README.md.
