# Lantern — a little light for your day
An original 30-second animated launch-film concept for a **fictional** family AI. No real monitoring product, family data, photography, sampled audio or paid services.

## Watch
https://raj-microsoft.github.io/lantern-film/

## Reproduce
Python 3.12+, ffmpeg on PATH, `pip install numpy pillow`, then `python src/build_film.py`.
The script draws 900 RGB frames at 1920×1080 / 30 fps, pipes them into H.264, synthesizes an original 120 BPM stereo score using NumPy and wave, applies two-pass loudness normalization, muxes AAC, and remeasures the finished MP4. `--4k` redraws natively at 3840×2160; that optional output is not included.

Measured encoded master: **-16.00 LUFS**, true peak **-2.11 dBTP**, 30 seconds; MP4 1,330,581 bytes. Reports in `checks/` (input_i is the measured published file, output_i is the hypothetical further normalization).
